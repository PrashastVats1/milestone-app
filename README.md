# Milestone

Clear scope. Agreed changes. No surprises.

A project agreement and scope-change record for a freelancer and their client.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. Use the Freelancer / Client switcher in the header. Data stays in this browser's localStorage and is not synced to anyone else.

## Deploy

Import the repository on Vercel. Framework preset: Next.js. No environment variables.
